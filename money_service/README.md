# Money Service

Flask API для ведения финансовых операций (приходных и расходных): создание,
чтение, частичное обновление операций и баланс, с хранением данных в in-memory SQLite.

## Запуск

```bash
uv venv --python 3.11
uv pip install -e ".[dev]"
flask --app app run
```

Приложение запускается одной командой, внешних сервисов не требует.

## Категории по умолчанию

При старте БД предзаполняется категориями (`id` 1–11 в этом порядке):

- `income`: Зарплата, Шабашки, Долги
- `expense`: Продукты, Кино, Театр, Кофе, Ресторан, Столовая, Бензин, Квартплата

Операцию можно создавать сразу после запуска, без предварительного создания категорий.
Создание категории с уже существующим именем (включая предзаполненные) — `409`.
Отключить предзаполнение: `create_app(seed=False)` в коде (`app/__init__.py`).

## API

### `POST /categories`

```json
{"name": "Продукты", "type": "expense"}
```

- `201` — категория создана
- `400` — невалидное тело (неверный JSON, пустой/длинный `name`, неверный `type`)
- `409` — дубликат `name`

### `GET /categories`

- `200` — JSON-список всех категорий (по возрастанию `id`, включая предзаполненные), используется чтобы узнать `category_id` по имени

### `POST /operations`

```json
{"type": "expense", "amount": 25000, "category_id": 1, "comment": "Супермаркет"}
```

- `201` — операция создана
- `400` — невалидное тело (`amount <= 0`, неверный `type`, несоответствие типа операции и категории)
- `404` — категория не найдена

### `GET /operations`

- `200` — JSON-список всех операций (по возрастанию `id`)

### `GET /operations/<id>`

- `200` — операция
- `404` — операция не найдена

### `PATCH /operations/<id>`

```json
{"amount": 30000, "comment": "Супермаркет"}
```

Меняются только переданные поля (`type`, `amount`, `category_id`, `comment`);
`id` и `created_at` неизменяемы.

- `200` — обновлённая операция
- `400` — пустое тело, невалидные поля, попытка изменить `id`/`created_at`,
  несоответствие типа операции и новой категории
- `404` — операция или категория не найдена

### `GET /balance`

```json
{"balance": 60000}
```

Сумма приходных операций минус сумма расходных (в копейках, отрицательный допустим).

Ошибки возвращаются как `{"error": "<описание>"}`.

## Тесты

```bash
pytest --cov=app
```

Unit-тесты используют mock/monkeypatch репозиториев (без обращения к БД),
интеграционные тесты работают на in-memory SQLite.
